电动重卡融资 · 交叉点测算器
Electric Heavy Truck Financing — Crossover-Point Calculator
输入融资参数，看剩余本金与车辆残值在第几个月交叉、风险敞口期有多长。
为什么需要这个工具
电动重卡的残值到今天没有公认的准数——电池衰减、技术迭代、品牌存续都在影响它。残值定不了，融资风控最核心的问题就变成：这笔融资在哪个时点，车辆残值会盖不住还没还清的本金？
那个时点，就是「交叉点」。交叉点之前是风险敞口期（本金 > 残值），之后资产才能自保。
这个工具把交叉点算清楚，并让你看到首付、期限、利率、保证金各自对交叉点的影响有多大。
核心概念
- 交叉点：剩余本金曲线与车辆残值曲线的交点，单位是「第几个月」。
- 风险敞口期：交叉点之前，剩余本金高于残值的时间段。敞口期越长，处置风险越大。
- 无敞口：首付高到让融资本金从放款第一天起就低于上牌后价值，交叉点消失。

计算口径
这些口径决定了数字的含义，使用前请先看。
1. 残值假设：上牌后价值默认 70%，期末残值率随期限联动（36 月约 30%、48 月约 26%、60 月约 22%）。残值按裸车价计算，不含购置税。
2. 本金口径：融资租赁本金含购置税；车贷本金只算车价。
3. 保证金：按融资额（扣首付后）收取，不冲抵本金，因此不影响交叉点；但保证金无息占用，会推高实际成本。
4. IRR：实际年化成本（含月复利），略高于名义利率。
5. 月供：等额本息。
6. 临界首付：使融资本金首次低于上牌后价值的首付比例（车贷约 30%、融租约 35%，随残值假设变化）。
数字会随残值假设变化，机制不会。真正有用的是「每个参数往哪动、动多少」，而不是记住某个具体阈值。
